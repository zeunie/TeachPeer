# TeachPeer dataset

Anonymized data accompanying the manuscript *Human Explanatory Behaviour with an Imperfect LLM Partner* (Nature Communications).

Analysis code is in the sibling folder `TeachPeer_code`. These files are not required to run the analyses if you only want to inspect the raw data.

## Files

| File | N | Description |
| --- | --- | --- |
| `experiment_1.csv` | 549 | Corrective-feedback pairs from 115 learners, with human and baseline-LLM edit/uptake labels |
| `experiment_2_chat.csv` | 7,122 | Conversational turns from 170 Experiment 2 sessions (57 learners) |
| `experiment_2_essay.csv` | 171 | Learner essays, revisions, and LLM-peer essays from 171 sessions |
| `cognitive_load_data.csv` | 171 | Session-level cognitive-load and essay-improvement scores (57 learners × 3 sessions) |

One of 171 conducted Experiment 2 sessions is missing from `experiment_2_chat.csv` because of a data-logging issue. Cognitive-load and essay data include all 171 sessions.

Participant identifiers are anonymized separately in each file (`Pxxx` in Experiment 1 and the cognitive-load file; `Uxxx` in the Experiment 2 interaction and essay files) and should not be joined across files.

## experiment_1.csv

549 corrective-feedback–response pairs retained after excluding teacher turns that were not corrective feedback.

| Column | Description |
| --- | --- |
| `sample_id` | Interaction identifier (`PARTICIPANT-COURSE-WEEK-SESSION-INDEX`) |
| `participant_id` | Anonymized learner ID |
| `user` | Learner utterance |
| `chatgpt_after` | Teacher-LLM feedback |
| `rating` | Ancillary rating field |
| `intent_final` | Ancillary intent label |
| `prev_essay` | Essay before the turn |
| `essay` | Essay after the turn |
| `is_essay_edited_new` | Whether the learner edited the essay |
| `is_corrective_feedback` | Whether the teacher turn was corrective |
| `uptake_classification` | Human uptake: `SUCCESSFUL`, `UNSUCCESSFUL`, or `NO-UPTAKE` |
| `4o-is_essay_edited_new_new` | GPT-4o simulated edit flag |
| `4o-uptake_classification` | GPT-4o simulated uptake |
| `4o-mini-is_essay_edited_new_new` | GPT-4o-mini simulated edit flag |
| `4o-mini-uptake_classification` | GPT-4o-mini simulated uptake |
| `claude-is_essay_edited_new_new` | Claude-3.5-Sonnet simulated edit flag |
| `claude-uptake_classification` | Claude-3.5-Sonnet simulated uptake |
| `llama-is_essay_edited_new_new` | Llama-3.1-70B simulated edit flag |
| `llama-uptake_classification` | Llama-3.1-70B simulated uptake |

## experiment_2_chat.csv

7,122 turns: 2,445 learner (`user`), 3,484 peer (`assistant`), and 1,193 system messages.

| Column | Description |
| --- | --- |
| `uid` | Anonymized learner ID |
| `content` | Utterance text |
| `role` | `user`, `assistant`, or `system` |
| `session` | Session number (1–3) |
| `group_type` | Assigned LLM-peer profile: `low-uptake`, `high-uptake`, or `mixed-uptake` |
| `strategy` | Instructional-strategy code (learner turns) |
| `icap` | ICAP level (`Constructive`, `Active`, `Passive`) or `Others` |

Strategy analyses use all 2,445 learner utterances. ICAP analyses exclude 17 utterances coded `Others` (N = 2,428).

## experiment_2_essay.csv

| Column | Description |
| --- | --- |
| `uid` | Anonymized learner ID |
| `studentEssay` | Learner essay submitted at the start of the session |
| `studentJson` | Incorrect knowledge components extracted from the learner essay |
| `revised_essay` | Learner essay after the peer-teaching session |
| `peerEssay` | LLM-peer essay generated by error mirroring |
| `peerJson` | Knowledge components inserted into the peer essay |
| `group_type` | Assigned LLM-peer profile |

## cognitive_load_data.csv

| Column | Description |
| --- | --- |
| `participant_id` | Anonymized learner ID |
| `session` | Session number (1–3) |
| `group_type` | Assigned LLM-peer profile |
| `intrinsic_load` | Session-level intrinsic-load score |
| `extraneous_load` | Session-level extraneous-load score |
| `germane_load` | Session-level germane-load score |
| `essay_improvement` | Participant-level improvement score (repeated across that participant’s sessions) |

ANOVAs average session-level load scores within participant (N = 57; 19 per condition).

## Ethics

Both studies were approved by the institution’s research ethics board (KH2024-222). Identifiers in these files are anonymized. The released tables do not include names or email addresses.
